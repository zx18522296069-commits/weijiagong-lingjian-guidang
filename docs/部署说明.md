# 未加工零件自动归档系统部署说明

## 自动执行

GitHub Actions 使用北京时间：

- 17:25
- 22:00

## 运行环境

- Python
- GitHub Actions Runner
- Google Drive API

## 必要配置

GitHub Secret：

- GOOGLE_SERVICE_ACCOUNT_JSON

Drive 目录与固定输出文件 ID 由生产工作流环境变量配置；服务账号必须拥有这些目标的读取、覆盖和移动权限。

## 数据规则

- 板材编号唯一
- 编号包含“废”字时保留并独立识别
- 防止重复录入
- 整单全部图号剩余为0后，才从《当前待加工零件》移除
- 单张板完成文件入账并回读验证成功后，归档到“已录入数量”
- 无法确定性匹配时阻断，不做近似匹配
